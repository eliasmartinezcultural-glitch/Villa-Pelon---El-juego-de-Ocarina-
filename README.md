# VILLA PELÓN — Las aventuras de Luna

Prototipo jugable 0.1 de Ocarina Producciones.

## Jugar en tu computadora

1. Abrí `index.html` en un navegador moderno.
2. Elegí **Comenzar a explorar**.
3. Caminá con las flechas o WASD. Usá **E** o **Espacio** para hablar e investigar.

## Jugar en celular o tablet

Usá las flechas táctiles y el botón **ACCIÓN**. El botón **DIARIO** muestra el objetivo actual.

## Publicar con GitHub Pages

1. Entrá en **Settings** del repositorio.
2. Abrí **Pages** en el menú lateral.
3. En **Build and deployment**, elegí **Deploy from a branch**.
4. Seleccioná la rama `main` y la carpeta `/(root)`, luego guardá.
5. Esperá a que GitHub publique el sitio. La dirección será `https://eliasmartinezcultural-glitch.github.io/Villa-Pelon---El-juego-de-Ocarina-/`.

## Alcance de esta versión

- Mapa cenital pixel art con cámara que sigue a Luna.
- Movimiento con teclado y controles táctiles.
- Colisiones, edificios, personajes, objetos y diálogos.
- Primera misión con tres pistas, diario y estado de progreso.
- Sin bibliotecas externas, servidores ni costos.

## Criterio histórico

Esta primera versión es un prototipo de mecánicas y atmósfera, no una reconstrucción histórica verificada. Los lugares, fechas, edificios y personajes reales se incorporarán cuando existan fuentes confiables identificadas. Los elementos tecnológicos de la trama se consideran ficción narrativa.
